## About me

I'm **Thunderkeg**. I build and contribute to open-source software for **distributed data and AI infrastructure**.

My work spans **SQL analytics, data connectivity, and machine learning workflows**—from distributed training to model delivery and inference. I develop tools and contribute improvements across the **Spark, Ray, Daft, and Gravitino** ecosystems, with a focus on OLAP databases and lakehouse systems.
